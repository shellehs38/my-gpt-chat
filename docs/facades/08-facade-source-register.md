# 08. Реестр источников по фасадным работам

Реестр содержит отправные точки для систематического поиска. Он не означает, что уже просмотрены все документы на каждой странице. Для каждого конкретного фасада нужно сохранять применимые PDF/чертежи и записывать редакцию.

## А. Нормативные источники
1. [Росстандарт — Федеральный информационный фонд стандартов](https://protect.gost.ru/) — официальный поиск ГОСТ и СП, карточки документов и изменения.
2. [Минстрой России](https://minstroyrf.gov.ru/) — приказы и публикации по сводам правил.
3. [Официальный портал правовой информации](https://pravo.gov.ru/) — федеральные законы, постановления и приказы.
4. [МЧС России](https://mchs.gov.ru/dokumenty) — нормативные документы по пожарной безопасности.
5. [Минтруд России](https://mintrud.gov.ru/docs) — правила охраны труда.

## Д. Порядок добавления нового источника
Для каждой ссылки записать:
- дату обращения;
- издателя/производителя;
- точное название документа;
- номер и редакцию;
- дату выпуска/введения;
- тип источника: нормативный, проектный, системный, паспорт, монтажная инструкция, учебный;
- область применимости;
- статус проверки;
- какие требования или узлы извлечены;
- ограничения и противоречия с другими источниками.

## Е. Правило цитирования в ответах помощника
Если ответ содержит конкретный нормативный параметр, допуск, обязательное требование, пожарное ограничение или характеристику продукта, необходимо указывать документ/редакцию и ссылку. Если подтверждающий документ не найден в репозитории, сообщать, что данных недостаточно, и предлагать проверить официальный источник. Не выдавать рекламный текст производителя за независимое подтверждение.
