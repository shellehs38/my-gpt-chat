# 03. Чек-лист собеседования фасадчика

**Цель:** понять, что кандидат действительно умеет делать, а не только знает термины. Отмечать ответы и подтверждать опыт примерами, фото и практическим заданием.

Кандидат: ____________________  
Дата: ____________________  
Вид фасада: ____________________  
Проверяющий: ____________________

## А. Опыт и личная ответственность

- [ ] Назвал конкретные объекты, тип системы, облицовку и свою роль.
- [ ] Может объяснить, какие операции выполнял сам, а какие — бригада/подрядчик.
- [ ] Показывает фотографии работ с этапами до закрытия.
- [ ] Может назвать типовые ошибки, которые встречал, и как их исправляли.
- [ ] Знает, когда нужно остановить работу и запросить решение прораба/проектировщика.
- [ ] Не утверждает, что любой фасад монтируется одинаково.

Вопросы:
1. Опишите последний объект от подготовки основания до сдачи.
2. Какие скрытые работы вы фотографировали и почему?
3. Что делаете, если фактическая стена отличается от проекта?
4. Как поступите, если анкер проворачивается или основание осыпается?

## Б. Чтение проекта и измерения

- [ ] Читает фасадные развёртки, планы, разрезы и узлы.
- [ ] Понимает оси, отметки, размеры проёмов и раскладку облицовки.
- [ ] Пользуется рулеткой, уровнем/лазером, отвесом и измерительным инструментом.
- [ ] Проверяет плоскость и вертикаль до начала монтажа.
- [ ] Не меняет самовольно шаг креплений, вынос кронштейнов и узлы.
- [ ] Фиксирует расхождения и сообщает руководителю.

Практическое задание: дать простой узел и попросить объяснить последовательность монтажа, контрольные размеры и скрытые операции.

## В. Основание и крепёж

- [ ] Различает бетон, полнотелый/пустотелый кирпич, блок, дерево и каркасное основание.
- [ ] Понимает, что тип анкера зависит от основания и расчёта.
- [ ] Знает необходимость испытаний/проверки несущей способности, если это предписано.
- [ ] Не крепит тяжёлые элементы только к облицовке, если узел не рассчитан на это.
- [ ] Знает требования к подготовке отверстий и монтажу конкретного крепежа.

Контрольный вопрос: «Можно ли использовать один и тот же дюбель для газобетона, пустотелого кирпича и бетона?» Ожидаемый смысл ответа: нет, выбор зависит от основания, нагрузки, системы и расчётных данных.

## Г. Технология и качество

- [ ] Знает порядок работ для конкретного типа фасада.
- [ ] Различает несущие и декоративные элементы.
- [ ] Понимает назначение деформационных швов и температурных зазоров.
- [ ] Умеет выявлять повреждённые/несоответствующие материалы.
- [ ] Не закрывает скрытые работы до контроля и фотофиксации.
- [ ] Знает, как вести учёт материалов и не допускать загрязнения/намокания.
- [ ] Соблюдает инструкции производителя по хранению, приготовлению и монтажу.

## Д. Охрана труда

- [ ] Прошёл требуемое обучение и имеет необходимые допуски/подтверждения.
- [ ] Проверяет состояние лесов, настилов, ограждений и доступа.
- [ ] Понимает порядок применения страховочной системы и проверку точки крепления.
- [ ] Не работает на неисправном оборудовании или при запрещённых погодных условиях.
- [ ] Использует СИЗ и безопасно обращается с электроинструментом.
- [ ] Знает порядок сообщения об опасности и остановки работ.

Не допускать к высотным работам до подтверждения обязательных требований к обучению, медосмотрам и допускам, применимых к работодателю и виду работ.

## Е. Оценка кандидата

Оценивать каждую категорию от 0 до 2:
- 0 — не знает/опасный ответ;
- 1 — знает частично, нужна постоянная проверка;
- 2 — объясняет правильно и подтверждает опытом.

| Категория | Балл 0–2 | Комментарий |
|---|---:|---|
| Опыт и ответственность |  |  |
| Чтение проекта |  |  |
| Основание и крепёж |  |  |
| Технология фасада |  |  |
| Контроль качества |  |  |
| Охрана труда |  |  |
| Итого | /12 |  |

**Решение:**  
- [ ] Допустить к работе по проверенной квалификации  
- [ ] Допустить только под наблюдением  
- [ ] Провести практическую проверку  
- [ ] Не допускать к высотным/ответственным операциям до подтверждения квалификации

Баллы — внутренний инструмент отбора, не нормативная аттестация. Обязательные документы, обучение и допуски проверять отдельно.
