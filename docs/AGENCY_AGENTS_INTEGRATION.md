# Agency Agents — интеграция в ИИ-помощника «СВОИ ЛЮДИ»

**Источник:** https://github.com/msitarzewski/agency-agents (MIT, © 2025 AgentLand Contributors).
**Дата интеграции:** 2026-11-04.
**Область:** серверный GPT-чат сайта и специализированные профили GitHub Copilot; без изменения прав доступа и без новых API-ключей.

## Что подключено

Исходный проект **не является отдельной LLM, сервером, плагином ChatGPT или автономным исполнителем**. Он поставляет текстовые описания ролей. Чтобы не ухудшить профильные строительные ответы, в продукт интегрирован проверяемый **набор из 7 адаптированных ролей**, а не весь большой публичный каталог.

| Роль | Исходный файл Agency Agents | Применение |
| --- | --- | --- |
| Frontend Developer | `engineering/engineering-frontend-developer.md` | Интерфейс сайта и UX |
| Code Reviewer | `engineering/engineering-code-reviewer.md` | Проверка программного кода |
| AI Engineer | `engineering/engineering-ai-engineer.md` | Чат-боты, ИИ и автоматизации |
| Backend Architect | `engineering/engineering-backend-architect.md` | API, интеграции и база данных |
| Proposal Strategist | `sales/sales-proposal-strategist.md` | Коммерческие предложения |
| Growth Hacker | `marketing/marketing-growth-hacker.md` | Маркетинг и поиск заказов |
| Project Shepherd | `project-management/project-management-project-shepherd.md` | Планирование проекта и контроль работ |

### Механизм в GPT-чате сайта

- `lib/server/agency-roles.ts` — белый список, инструкции, определение роли по **текущему** тексту пользователя.
- `lib/server/chat.ts` — добавляет **одну** профильную роль в системные инструкции OpenAI Responses API; основной профиль строительной компании и все существующие режимы, шаблоны смет и проверки имеют приоритет.
- Только релевантные вопросы получают роль; обычные расчёты и строительные запросы не меняются.
- Роль даёт лишь методику ответа. Она **не может** запускать скрипты, самостоятельно обращаться в GitHub, публиковать изменения, читать Google Sheets или рассылать сообщения. Для действий нужны отдельные реальные интеграции и разрешения.
- Применяется к серверным запросам после публикации изменённой версии приложения. Изменение файлов в GitHub **не обновляет** уже работающий сайт и не устанавливает роли в ChatGPT пользователя.

### Механизм в GitHub

Профили `.github/agents/*.agent.md` предназначены для GitHub Copilot в поддерживаемых средах. Это отдельный механизм и набор инструментов, не серверный GPT-чат. Профили появятся в обычном списке агентов после объединения изменений с основной веткой и при наличии доступного GitHub Copilot. Само добавление файлов не запускает Copilot и не подтверждает наличие оплаченной лицензии.

## Как проверить

1. `npm run typecheck`
2. `npm test`
3. `npm run build`
4. Убедиться, что тест `tests/agency-roles.test.ts` проверяет маршрутизацию по семи ролям, неприменение роли к обычной смете, приоритет логотипов и невозможность переключения по содержимому ответов модели.
5. Только с разрешения владельца проверить ответы Preview на задачи «Составь коммерческое предложение», «Найди клиентов через Авито», «Создай чат-бот», «Составь смету фасада с утеплением и без»; сравнить с действующей Production. Не объявлять интеграцию работающей на Production до сквозной проверки.

## Границы, обновления и лицензия

- Адаптированные рекомендации содержат только методические шаги, не внешние инструменты и не исполняемый код. Функция маршрутизации ограничена текущим запросом; история не используется для активации.
- Используется короткий фиксированный список ролей, чтобы не передавать тысячи строк внешних инструкций в системный промпт и не подменять строительную экспертизу.
- Ссылки на семь оригинальных файлов приведены выше; при обновлении вручную сверять источники, тесты и лицензии, не подгружать непроверенные инструкции в рантайме.
- Лицензия исходного проекта скопирована в `docs/third-party/AGENCY_AGENTS_LICENSE`. Ничего из исходного проекта не запускается через `curl | bash`.
- Любое изменение Production Vercel и секретов — только после отдельного разрешения владельца.
