# Ruflo: подключение MCP к Codex (эксперимент)

## Статус на 19.11.2026

В каталоге ChatGPT готовый плагин Ruflo не найден. В текущем чате нет доступа к установленному у владельца Codex CLI, поэтому постоянное подключение и запуск не подтверждены. Подготовлен отдельный пример конфигурации. Не заменять существующие настройки Codex, Superpowers, Composio, Graphify, Codebase Memory и маршрутизаторов.

Официальный проект: https://github.com/ruvnet/ruflo
Документация установки: https://github.com/ruvnet/ruflo/blob/main/docs/ruflo-explained.md
Пакет: https://www.npmjs.com/package/ruflo
Версия 3.38.23 — зафиксированный пример в официальной инструкции, а не утверждение о новейшей или проверенной безопасной версии.

## Порядок подключения

1. Определить, есть ли доступный терминал Codex CLI, Node.js версии 20 или новее и npm/npx. Проверить текущую версию Codex и список MCP. Не устанавливать второй экземпляр.
2. Проверить происхождение пакета, версию, зависимости, install scripts, известные уязвимости и требуемые разрешения. Начать в изолированной тестовой среде без настоящих ключей, личных данных и доступа к Production. Не выполнять удалённые shell-скрипты и не использовать latest без ревью.
3. После проверки пакета добавить только Ruflo MCP. Пример upstream:
   `codex mcp add ruflo -- npx --yes ruflo@3.38.23 mcp start`
   Альтернатива: вручную объединить пример tools/codex/ruflo-mcp.config.toml.example с пользовательской конфигурацией, если это поддерживается клиентом. Не применять оба способа одновременно.
4. Выполнить `codex mcp list`, перезапустить сеанс, проверить обнаружение инструментов и фактический безопасный read-only вызов. Не считать регистрацию доказательством работающего сервера.
5. Выполнить тестовую задачу на синтетическом проекте: максимум два независимых агента, без платных внешних запросов, записи клиентских данных, push или deploy. Сравнить с обычным Codex по качеству, времени и расходу токенов. Зафиксировать реальные результаты.
6. Только после успешной проверки использовать в сложных задачах в пределах разрешений владельца. При недоступности Ruflo применять штатные инструменты и указывать ограничение.

Не запускать init --codex в существующем репозитории без предварительного просмотра изменений в изолированной копии: инициализация может создавать hooks, файлы конфигурации и память. Не сохранять локальную базу, секреты или артефакты сеансов в GitHub.

## Разделение ответственности

Ruflo — координация независимых задач и агентов; Superpowers — план, тестирование, ревью и доказательства; Composio — внешние операции с авторизацией; Codebase Memory и Graphify — анализ кода; OmniRoute и FreeLLMAPI — отдельные шлюзы. Не включать новый модельный провайдер либо платный fallback автоматически. Оркестрация не увеличивает квоту ChatGPT/Codex и может увеличить потребление токенов.

## Облачные клиенты

Локальный stdio MCP не становится доступным в мобильном ChatGPT, Work или облачном Codex автоматически. Проверять реальную поддержку транспорта отдельно. Для удалённого режима требуется защищённый аутентифицированный MCP endpoint с ограниченными инструментами, проверкой прав и отдельным согласованием инфраструктуры. Не публиковать сервер с доступом к файлам или shell без авторизации. В рамках этой задачи сервер Railway не создаётся и Production не изменяется.
