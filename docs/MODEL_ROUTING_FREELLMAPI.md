# Экономия токенов и переключение моделей — FreeLLMAPI

Дата: 2026-11-04.
Область: **только серверный чат сайта ООО «СВОИ ЛЮДИ»** `/api/chat` и общий Native API, где используется `handleAuthenticatedChat`. **Не меняет подписку и лимиты приложения ChatGPT и не подключает модели к аккаунту ChatGPT.**

Исходный проект (не копируется внутрь Next.js): [tashfeenahmed/freellmapi](https://github.com/tashfeenahmed/freellmapi), MIT. Альтернативные форки существуют; перед использованием сверять оригинал, релиз, условия сервисов и зависимости.

## Внедрено в GitHub

- `lib/server/model-router.ts`: строго заданный белый список провайдеров, классификация запроса по сложности, ограничение объёма ответа и ограниченный переход к следующей модели на 408/429/5xx и сетевых сбоях.
- `lib/server/chat-handler.ts`: передаёт **одинаковые** инструкции, системные правила компании, контекст Codebase Memory, выбранный объект и доступную историю сообщений в каждый вызов, в том числе после перехода к следующей модели.
- `tests/model-router.test.ts`: тесты маршрутизации, контекста, защиты ключей, запрета нежелательных платежей и отказов.
- В ответе `/api/chat` теперь есть необязательное диагностическое поле `routing: { provider, model, tier, attempts }` (без секретов); существующий формат `reply/calculation/memory` сохранён.
- Используются уже существующие ограничения сеанса, частоты, запросов и валидации ответов.

## Что значит «контекст не теряется»

Каждая модель получает **один и тот же вход**, без зависимости от памяти прежнего провайдера: текущий запрос, историю, переданную текущим клиентом (максимум 16 сообщений), инструкции выбранного режима, строительные справочники по теме и опубликованный снимок правил Codebase Memory. На Native-клиенте передаётся также выбранный объект, когда он имеется.

**Это не полный архив прошлых разговоров ChatGPT.** Сайт пока не имеет доступа к личной памяти ChatGPT, всем предыдущим перепискам, всем документам Google Drive или всей истории объектов. Публикация в GitHub не создаёт такой доступ автоматически. Полную долговременную память необходимо отдельно проектировать как базу данных с согласованными правами, выборкой и удалением личных данных.

## По умолчанию безопасно

**Все переключения выключены, пока `ASSISTANT_MODEL_ROUTER=on` не установлен в серверном окружении.** Это сохраняет прежний вызов `OPENAI_MODEL` с прежним максимумом 8000 выходных токенов. Настройки не должны автоматически менять Production и не должны добавлять новые расходы.

При включённом роутере:

1. Простые вопросы в общем режиме → `ASSISTANT_ECONOMY_MODEL`, максимум 1600 выходных токенов.
2. Фасады, технологии, сметы, документы → `ASSISTANT_QUALITY_MODEL`, максимум 8000.
3. Высокорисковые инженерные вопросы, несущие конструкции, безопасность и экспертные заключения → `ASSISTANT_EXPERT_MODEL`, максимум 8000.
4. Для ошибок временной недоступности или отсутствующей модели можно отдельно разрешить резерв через `ASSISTANT_MODEL_FALLBACK=on`: expert → quality → проверенная базовая, economy/quality → базовая. Не более трёх попыток, не более дорогой модели для сбойного простого запроса. По умолчанию резерв отключён.
5. Параметры моделей выбирает владелец после проверки доступности **в его OpenAI API**, цен, лимитов и качества. Примеры: экономичная `gpt-6-luna`; качественная `gpt-6.1-terra`. Названия не означают, что эти модели доступны любому API-ключу, и не гарантируют качества Astra.

Ошибки 401/403, неверные запросы, отказы по безопасности, повреждённые ответы и ошибки структуры сметы **не** запускают неограниченный повтор. Совокупный таймаут по-прежнему 30 секунд. Встроенные лимиты сеанса остаются и не равны счётчику расходов API.

## Внешний FreeLLMAPI — только после отдельной настройки

Сам FreeLLMAPI использует SQLite и долгоживущий сервис. Его нельзя просто скопировать в GitHub и считать запущенным в Vercel Serverless. Нужен самостоятельный сервер/хостинг с защищённым HTTPS, проверенными версиями, отдельным API-ключом шлюза и разрешёнными ключами конкретных провайдеров.

Настройка серверного клиента (секреты НЕ в репозитории):
```env
ASSISTANT_MODEL_ROUTER=on
# Выбор в рамках OpenAI; только после проверки API-ключа и стоимости:
ASSISTANT_ECONOMY_MODEL=gpt-6-luna
ASSISTANT_QUALITY_MODEL=gpt-6.1-terra
ASSISTANT_EXPERT_MODEL=gpt-6.1-sol
# ASSISTANT_MODEL_FALLBACK=on

# FreeLLMAPI должен работать на отдельном защищённом HTTPS-хосте
# FREELLMAPI_BASE_URL=https://your-router.example/v1
# FREELLMAPI_API_KEY=replace-in-server-secret-only
# FREELLMAPI_MODEL=auto
# FREELLMAPI_ENABLED=on
# FREELLMAPI_EXTERNAL_DATA_APPROVED=I_APPROVE_EXTERNAL_PROCESSING
# FREELLMAPI_PAID_FALLBACK=on
```

**Все** пять условий нужны для внешней отправки: включённый роутер, включённый FreeLLMAPI, корректный HTTPS URL, отдельный ключ и точное подтверждение передачи данных сторонним провайдерам. Если подтверждения нет, ни одно сообщение туда не уходит. По умолчанию FreeLLMAPI вызывается только для экономичных запросов `general`. Дальнейший переход к платному OpenAI отключён, пока владелец явно не включит `FREELLMAPI_PAID_FALLBACK=on`. Применимость к данным компании зависит от правил всех провайдеров — **«бесплатно» не означает допустимость коммерческого использования, отсутствие лимитов или конфиденциальность**.

Не включать внешнюю отправку документов заказчиков, телефонов, адресов, смет или коммерческих секретов до отдельной проверки поставщика, его политики данных и правовых требований. Если FreeLLMAPI выключен, проект продолжает использовать исходный OpenAI API.

## Проверка перед выпуском

1. `npm run typecheck`, `npm test`, `npm run build`.
2. Убедиться, что без новых переменных поведение Production идентично прежнему.
3. На Preview проверить обычный вопрос, длинный текст, фасадную смету, продолжение диалога, переключение модели при 429, ошибки поставщика.
4. Проверить лимиты затрат и реальные метрики в панели OpenAI и у выбранного провайдера; не рассчитывать экономию по рекламным цифрам.
5. Обновить `docs/CODEBASE_MEMORY_ADR.md`, индекс `npm run memory:index` и `memory:check`. После запуска дать ссылку на рабочий сайт, проверить соответствие коммита и раздельно оценить качество и стоимость.

## Чего этот этап не делает

- Не обходит квоты ChatGPT Plus/Pro и не меняет модель, обслуживающую текущую переписку в ChatGPT.
- Не запускает бесплатный прокси FreeLLMAPI на GitHub или Vercel.
- Не гарантирует бесплатные запросы, снижение расходов или экспертность уровня Astra.
- Не копирует персональные переписки ChatGPT в GitHub и не подключает скрытые пользовательские данные.
- Не меняет секреты, биллинг, данные клиентов или Production без отдельного разрешения владельца.

### Коммерческое применение

Разработчики FreeLLMAPI описывают продукт как инструмент личных экспериментов, **не рекомендованный для Production**. Бесплатные квоты поставщиков могут запрещать применение как продуктивного бизнес-бэкенда. Для реальных клиентских данных используем в Production маршрутизацию между оплачиваемыми OpenAI API-моделями. FreeLLMAPI не активируем без отдельно развёрнутого постоянного HTTPS сервера с SQLite и разрешённых поставщиков. Обычный Vercel Serverless не может обеспечить долговременное файловое хранение SQLite.
