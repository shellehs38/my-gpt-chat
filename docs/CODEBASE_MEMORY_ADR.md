# Версионируемая память архитектуры «СВОИ ЛЮДИ»

Этот файл хранится в GitHub. `npm run memory:index` переносит только указанные секции в ADR индекса; другие секции, добавленные разработчиком, сохраняются.

## PROJECT BASELINE

Веб-помощник ООО «СВОИ ЛЮДИ», Иркутск. Next.js 15, React 19, TypeScript, Node.js >=22. Главная страница: app/page.tsx. Серверные API: app/api/auth, app/api/chat, app/api/ledger. OpenAI вызывается только сервером. Подписка ChatGPT не заменяет API-доступ. MAX остаётся отдельной интеграцией.

## DOMAIN RULES

Расчёты смет находятся в lib/estimate.ts; деньги рассчитываются точно, без подмены неизвестных значений нулём. Клиенты, объекты и расходы связываются по ID, а не по одной фамилии. Неоднозначный выбор требует уточнения. Ledger использует атомарные пакеты Sheets, UUID команды и постоянные квитанции для безопасного повтора. Сохранение подтверждается контрольным чтением; ручные изменения не перезаписываются повтором.

## ACCESS AND STORAGE

API защищены входом владельца, подписанной HttpOnly-сессией и проверкой источника записи. Ключи и заполненные env-файлы не хранятся в GitHub и не передаются в браузер. Проект и версии смет сохраняются в браузере с JSON-резервированием. Учёт использует отдельный серверный сервисный аккаунт Google и рабочую Google Таблицу; подключение Drive к ChatGPT не передаёт доступ сайту. Лимиты процесса не считаются общим бюджетным лимитом распределённого сервиса.

## COMPANY DOCUMENT BRANDING

Постоянное правило владельца: каждый новый документ ООО «СВОИ ЛЮДИ», включая смету, КП, договор, акт, ведомость и отчёт, содержит подлинный логотип SL / «СВОИ ЛЮДИ» в шапке. Полный регламент: DOCUMENT_BRANDING.md. Исходный PNG: public/brand/logo-sl-approved-light.png. HTML-выгрузка встраивает изображение; PDF через печать должен сохранять его. Схему рабочей таблицы не сдвигают ради оформления.

## DEVELOPMENT MEMORY

Codebase Memory 0.12.1 — вспомогательный индекс кода и ADR для разработки. Источники, AGENTS.md, DOCUMENT_BRANDING.md и тесты имеют приоритет над устаревшим графом. Перед выводами об отсутствии функций или полном влиянии изменений проверяй свежесть индекса, охват файлов и реальный исходный код. После изменений запускай memory:index повторно. Учёт клиентов и секреты не записываются в архитектурную память.

## SHARED CHAT MEMORY

При каждой production-сборке реальный Codebase Memory строит индекс и ADR, затем scripts/export-codebase-memory.mjs выгружает разрешённые публичные правила и расположения символов в data/codebase-memory.json. GPT-чат сайта получает эти правила в серверном контексте каждого запроса. Плагин ChatGPT читает тот же снимок через публичный MCP Streamable HTTP /api/mcp: get_project_memory, get_memory_status, search_codebase, get_file_outline. Это адаптер чтения снимка, не полный нативный движок и не автоматическое хранение переписки. Отпечаток и ревизия позволяют сравнить память двух клиентов. Клиенты, расходы, секреты и личные сообщения в публичную память не входят. Новые правила меняются в исходном ADR и вступают в силу после сборки.
