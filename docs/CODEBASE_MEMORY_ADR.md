# Версионируемая память архитектуры «СВОИ ЛЮДИ»

Этот файл хранится в GitHub. `npm run memory:index` синхронизирует перечисленные разделы с ADR-индексом, не удаляя пользовательские разделы.

## PROJECT BASELINE

Веб-помощник ООО «СВОИ ЛЮДИ», Иркутск: Next.js 15, React 19, TypeScript, Node.js >=22. Интерфейс — app/page.tsx; API — app/api/auth, chat, ledger и drive. OpenAI вызывается только сервером. Подписка ChatGPT не даёт API-доступ. MAX остаётся отдельной интеграцией.

## DOMAIN RULES

Сметы рассчитывает lib/estimate.ts точной денежной арифметикой; неизвестное значение не равно нулю. Структурированные строки и детерминированный пересчёт — источник итогов для экрана, контекста и выгрузки; старые денежные итоги в прозе удаляются. Текущее отрицание фасадной задачи важнее истории. Клиенты, объекты и расходы связываются по ID; неоднозначность требует выбора. Ledger применяет атомарные Sheets-пакеты, UUID, постоянные квитанции и контрольное чтение, не затирая ручные правки при повторе.

## ASSISTANT MODES

Вкладки: general — вопросы; estimate — сметы; engineering — технологии; facade — фасадные системы; business — Sheets-учёт либо продажи без записи; documents — КП, договоры, акты и письма. assistant-modes.ts задаёт UI, server/chat.ts — роли. modeState и mode изолируют историю, черновики, ответы и повторы; поздний ответ возвращается в исходную вкладку. Decode не переписывает старые снимки ради Drive SHA-256. Новый предмет вопроса важнее истории. `calculation=none` сохраняет суммы документов без сметного пересчёта.

## ACCESS AND STORAGE

API защищены входом владельца, подписанной HttpOnly-сессией и проверкой источника. Секреты не попадают в GitHub и браузер. Проект сначала сохраняется локально; отдельное OAuth-подключение добавляет неизменяемую историю Google Drive. Доступ к проекту и резервным копиям открыт только после входа. Выход с очисткой удаляет локальный проект, очередь Drive и незавершённую команду учёта, сохраняя облачную историю. Учёт использует отдельный сервисный аккаунт Sheets. Подключение Drive к ChatGPT не даёт доступ сайту. Лимит процесса не является общим бюджетным лимитом.

## COMPANY DOCUMENT BRANDING

Каждый новый документ ООО «СВОИ ЛЮДИ» — смета, КП, договор, акт, ведомость или отчёт — содержит подлинный логотип в шапке. Регламент: DOCUMENT_BRANDING.md. Исходник: public/brand/logo-sl-approved-light.png. HTML встраивает изображение; печать в PDF должна его сохранять. Схему рабочей таблицы ради оформления не сдвигают.

## GOOGLE DRIVE CONNECTION STAGE

Серверный OAuth использует openid + drive.file и стабильного owner. DriveAutosave пишет неизменяемые JSON-снимки, durable outbox и повторяемый ID; успех требует проверки папки, размера, SHA-256 и чтения. Ветки выбирает пользователь. Локальная очистка удаляет outbox и ставит синхронизацию на паузу, не удаляя облако. Фото и отдельный public/facade-calculator в workspace Drive не входят.

## DEVELOPMENT MEMORY

Codebase Memory 0.12.1 — вспомогательный индекс. Исходники, AGENTS.md, DOCUMENT_BRANDING.md и тесты приоритетнее старого графа. Перед выводом об отсутствии функции проверяют свежесть и охват индекса. После изменений запускают memory:index. Клиенты, расходы, секреты и env в память не записывают.

## SHARED CHAT MEMORY

Сборка индексирует память и создаёт data/codebase-memory.json. Серверный чат получает эти правила; MCP /api/mcp предоставляет четыре инструмента чтения, а GET /api/project-memory — status и sections. Снимок публичный и только для чтения: без клиентов, расходов, секретов и переписки. revision/fingerprint указывают версию. Правила меняют здесь и публикуют новой сборкой.

## CONSTRUCTION KNOWLEDGE

Источники: plugin-source/svoi-lyudi-builder/skills/construction-assistant/references. Утверждённый проект и обязательные требования действуют совместно; конфликт передают проектировщику. Применяют техкарту конкретного продукта и подтверждённые данные, затем явно отмеченное допущение. Нормы и крепёж не переносят между продуктами. Расчёт и фото не заменяют обследование, проект или приёмку. Неизвестные цены и количества оставляют пустыми; ноль означает подтверждённое отсутствие стоимости. Денежный остаток не называют прибылью. Нормативный вывод сверяют с действующим первоисточником.

## FACADE MATERIAL CATALOG

system-catalog.mjs содержит 27 систем и 10 профилей металла; runtime — lib/server/facade-catalog.ts. Публичные карточки и монтаж: `/facade-calculator/catalog.json` и `materials-guide.md`. Состав зависит от системы; сердечник считают один раз. Неизвестный замок уточняют. Чат не вызывает движок. Подробнее: docs/FACADE_CALCULATOR.md.
