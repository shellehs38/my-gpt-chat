# Версионируемая память архитектуры «СВОИ ЛЮДИ»

Этот файл хранится в GitHub. `npm run memory:index` переносит только указанные секции в ADR индекса; другие секции, добавленные разработчиком, сохраняются.

## PROJECT BASELINE

Веб-помощник ООО «СВОИ ЛЮДИ», Иркутск. Next.js 15, React 19, TypeScript, Node.js >=22. Главная страница: app/page.tsx. Серверные API: app/api/auth, app/api/chat, app/api/ledger. OpenAI вызывается только сервером. Подписка ChatGPT не заменяет API-доступ. MAX остаётся отдельной интеграцией.

## DOMAIN RULES

Расчёты смет находятся в lib/estimate.ts; деньги рассчитываются точно, без подмены неизвестных значений нулём. Клиенты, объекты и расходы связываются по ID, а не по одной фамилии. Неоднозначный выбор требует уточнения. Ledger использует атомарные пакеты Sheets, UUID команды и постоянные квитанции для безопасного повтора. Сохранение подтверждается контрольным чтением; ручные изменения не перезаписываются повтором.

## ASSISTANT MODES

Шесть вкладок: general — вопросы и планирование; estimate — объёмы, арифметика и сметы любых работ; engineering — технологии и узлы; facade — фасадные системы; business — Sheets-учёт и отдельная консультация по продажам без записи; documents — КП, договоры, акты и письма. assistant-modes.ts задаёт интерфейс, server/chat.ts — роли. modeState и метки mode разделяют историю, черновики, ответы и повторы; поздний ответ относится к исходной вкладке. Старый decode не мигрирует данные ради Drive SHA-256. Фасадные настройки не наследуются другими вкладками. Новый предмет вопроса имеет приоритет. Новые версии с calculation=none сохраняют таблицы и суммы документов без сметного пересчёта; старые версии читаются прежним способом.

## ACCESS AND STORAGE

API защищены входом владельца, подписанной HttpOnly-сессией и проверкой источника записи. Ключи и заполненные env-файлы не хранятся в GitHub и не передаются в браузер. Проект и версии смет сохраняются в браузере с JSON-резервированием. Учёт использует отдельный серверный сервисный аккаунт Google и рабочую Google Таблицу; подключение Drive к ChatGPT не передаёт доступ сайту. Лимиты процесса не считаются общим бюджетным лимитом распределённого сервиса.

## COMPANY DOCUMENT BRANDING

Постоянное правило владельца: каждый новый документ ООО «СВОИ ЛЮДИ», включая смету, КП, договор, акт, ведомость и отчёт, содержит подлинный логотип SL / «СВОИ ЛЮДИ» в шапке. Полный регламент: DOCUMENT_BRANDING.md. Исходный PNG: public/brand/logo-sl-approved-light.png. HTML-выгрузка встраивает изображение; PDF через печать должен сохранять его. Схему рабочей таблицы не сдвигают ради оформления.

## GOOGLE DRIVE CONNECTION STAGE

OAuth на сервере: openid + drive.file, стабильный owner, вход по нажатию при необходимости. DriveAutosave сохраняет неизменяемые JSON-версии workspace, durable outbox и ID повтора; saved требует проверки папки, размера, SHA-256 и чтения. Ветки — до явного выбора. Local clear ставит паузу, не удаляет облако. JSON и Sheets сохраняются. Фото не интегрированы. public/facade-calculator доступен из вкладок смет/фасадов; его проекты хранятся отдельно от диалога и Drive.

## DEVELOPMENT MEMORY

Codebase Memory 0.12.1 — вспомогательный индекс кода и ADR для разработки. Источники, AGENTS.md, DOCUMENT_BRANDING.md и тесты имеют приоритет над устаревшим графом. Перед выводами об отсутствии функций или полном влиянии изменений проверяй свежесть индекса, охват файлов и реальный исходный код. После изменений запускай memory:index повторно. Учёт клиентов и секреты не записываются в архитектурную память.

## SHARED CHAT MEMORY

Production-сборка индексирует Codebase Memory и ADR, scripts/export-codebase-memory.mjs создаёт публичный data/codebase-memory.json. Серверный чат получает эти правила. MCP /api/mcp даёт get_project_memory, get_memory_status, search_codebase, get_file_outline; резервный GET /api/project-memory — только status и sections. Это сборочный снимок чтения, не полный движок и не хранение переписки. Нет клиентов, расходов, секретов и env. revision/fingerprint связывают клиентов с одной версией. Правила меняются в исходном ADR и публикуются сборкой.

## CONSTRUCTION KNOWLEDGE

База: plugin-source/svoi-lyudi-builder/skills/construction-assistant/references; фасады, технологии, сметы, качество, безопасность и логистика. Обязательные требования и утверждённый проект выполняются совместно; конфликт передаётся проектировщику. Используются техкарта конкретного продукта, подтверждённые данные, затем отмеченное допущение. Не переносить нормы, крепёж, допуски и выдержки между продуктами; не выдавать расчёт/фото за обследование, проект или приёмку. Неизвестные цены и количества пустые; ноль — подтверждённое отсутствие стоимости. Учёт по ID, денежный остаток не прибыль. Нормативный вывод требует проверки действующего первоисточника.
