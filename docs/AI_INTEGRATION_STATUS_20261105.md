## Главные правила

1. **Приоритет владельца — качество, а не скорость или минимальный расход токенов.** Сохранять выбранные веса 58/32/10, пока владелец их не изменит. Вес интеллекта не является процентом точности.
2. Внешний сервис выбирает модели только для запросов, которые действительно поступили в его API. Нельзя обещать переключение модели, обслуживающей ChatGPT, ChatGPT Work или облачный Codex.
3. ChatGPT Work через GitHub читает проект по запросу и в рамках доступов. Codex через `AGENTS.md` читает правила при работе в нужном репозитории. **Ни один механизм не даёт автоматической синхронизации всех личных чатов**.
4. Не переносить клиентские имена, контакты, адреса, сметы или коммерческие документы во внешние LLM без отдельной проверки условий и явного согласования; не подключать платные API без бюджета/разрешения.
5. Использовать точные технические идентификаторы моделей и провайдеров только после запроса текущего `/v1/models` или каталога. Публичный каталог FreeLLMAPI может содержать устаревшие и неподдерживаемые записи.
