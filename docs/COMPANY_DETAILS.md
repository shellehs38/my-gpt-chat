# Реквизиты ООО «СВОИ ЛЮДИ» и автозаполнение

По прямому поручению владельца в GitHub сохраняется карточка его организации.
Это реквизиты компании для документов; сведения о заказчиках, объектах и переписка сюда не добавляются.
Источник — данные владельца и последнее исправление фамилии: **Касинич Сергей Юрьевич**, **Генеральный директор**.

## Источник данных

Машиночитаемая карточка: [data/company-profile.json](../data/company-profile.json).
ИНН, КПП, ОГРН, банковские счета и БИК хранятся строками; ведущий ноль БИК сохраняется.
Публичная память для ChatGPT/Work содержит основные реквизиты в разделе `COMPANY REQUISITES`
файла [CODEBASE_MEMORY_ADR.md](CODEBASE_MEMORY_ADR.md).

Если документу нужны реквизиты ООО «СВОИ ЛЮДИ» или данные его руководителя, заполняй их сразу из карточки.
Не проси владельца присылать их повторно. Не переноси их в поля заказчика или другой организации.
Явно указанные пользователем данные конкретного документа сохраняй. Основание полномочий,
телефон, email, налоговый режим и НДС владельцем не подтверждены; их не выдумывать.
Заполнение имени подписанта не означает, что документ подписан или утверждён.

## Применение в помощнике и экспорте

`lib/company-profile.ts` добавляет карточку в инструкции всех шести режимов помощника.
При составлении документов модель получает сами реквизиты и правило их автоматического использования.

Для детерминированного заполнения полей шаблонов PDF/DOCX/XLSX/HTML и текстовой копии поддерживаются:

```text
{{company.shortName}}
{{company.fullName}}
{{company.legalAddress}}
{{company.inn}}
{{company.kpp}}
{{company.ogrn}}
{{company.settlementAccount}}
{{company.bank.name}}
{{company.bank.inn}}
{{company.bank.bic}}
{{company.bank.correspondentAccount}}
{{company.bank.legalAddress}}
{{company.director.fullName}}
{{company.director.position}}
```

Экспорт заполняет только эти явно названные поля. Существующие значения, суммы, общие поля
`[заполнить]`, реквизиты заказчика и неподдерживаемые маркеры остаются без изменений.
В HTML вставляемые значения экранируются.

После изменения карточки синхронизируй раздел ADR и выполни тесты и `npm run memory:index` / `npm run memory:check`.
Обновление GitHub-ветки само по себе не меняет Production и опубликованный MCP-снимок;
общая память обновится после принятия изменений и новой сборки.
