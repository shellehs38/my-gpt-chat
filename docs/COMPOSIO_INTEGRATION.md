# Composio: обязательные правила интеграций

## Назначение
Composio — единый слой доступа к авторизованным внешним приложениям для подходящих межсервисных задач. Он не заменяет LLM, Codebase Memory, FreeLLMAPI, OmniRoute или существующий учёт.

## Подтверждено
- Hosted Composio доступен в ChatGPT.
- Авторизация GitHub для аккаунта shellehs38 подтверждена состоянием active.
- Через Composio успешно прочитан AGENTS.md из main репозитория shellehs38/my-gpt-chat. Blob SHA: 2b7dedc8275658d3ec2d8b107b04e7b3122dd933.
- Доступ к другим приложениям, отдельной среде Codex Cloud, Work и Telegram-боту не подтверждён этой проверкой.

## Обязательный порядок
1. Для межсервисной задачи прочитать AGENTS.md и определить нужное приложение, действие, аккаунт, объём данных и права.
2. Проверить доступность Composio и активной авторизации, найти поддерживаемый инструмент и проверить его схему. При отсутствии авторизации запросить конкретное разрешение владельца.
3. Для подходящей разрешённой операции применять Composio. В hosted ChatGPT использовать доступные hosted tools; в Codex CLI использовать установленный и авторизованный CLI или поддерживаемый MCP согласно актуальной документации. Не считать GitHub-коммит установкой Composio в другой среде.
4. Для записи подтвердить точный ресурс и payload в пределах поручения, проверить результат по ID, SHA или URL. При неопределённом результате сначала читать состояние; не повторять запись автоматически.
5. Сохранять решения и результаты в GitHub: PR, проверки, статус, ограничения, ссылки. Не записывать ключи и персональные данные.
6. Если Composio недоступен для конкретной задачи, использовать допустимый штатный инструмент без обхода ограничений и документировать причину. Не устанавливать сервисы повторно и не подключать все приложения без нужного сценария.

## Следующие контрольные проверки
- Отдельно проверить Composio в реальных сеансах Codex/Work.
- По отдельным авторизациям проверить доступ к Google Drive/Sheets/Calendar/Gmail; использовать синтетические данные, не трогать существующий учёт.
- Telegram и сайт: отдельный тестовый адаптер только после определения разрешений, лицензии и бюджета. Не считать подключёнными по наличию hosted app.

## Ограничения
Никаких автоматических изменений Production, реальных данных, платных тарифов, ключей или пересылки конфиденциальных документов. Сначала проверяем техническую необходимость и полномочия.
