# Память проекта my-gpt-chat

Этот файл — краткая постоянная память о целях проекта и принятых договорённостях. Обновлять его при существенных изменениях.

## Назначение

Создать строительного AI-помощника для ООО «СВОИ ЛЮДИ» (Иркутск), который помогает с технологиями строительства, расчётами, сметами, документами, продажами и управлением проектами.

## Принцип ведения проекта

- GitHub — основной источник истины по коду, проектным решениям, плану работ и проверенным материалам.
- Все изменения кода фиксируются коммитами.
- Существенные обсуждения и решения записываются в `docs/DECISIONS.md` и/или `docs/WORK_LOG.md`.
- Задачи и приоритеты ведутся в `docs/ROADMAP.md`.
- Изменения разрабатываются в отдельной ветке и проверяются до слияния в `main`.
- Не утверждать, что функция работает, пока она не проверена.
- Не придумывать цены, нормативные значения, характеристики материалов и результаты проверок. Отмечать неизвестные данные.

- Ветка включает обновлённые инструкции строительного помощника, режимы работы, Markdown-рендеринг и мобильный интерфейс. Сборку и работу preview необходимо подтвердить по статусам проверок.

## Планируемые направления

1. Строительные технологии и инженерные риски: фундаменты, земляные работы, стены, перекрытия, кровля, утепление, гидроизоляция, подпорные стены, армирование, опалубка, бетон, дренаж.
2. Фасады, сайдинг, панели и вентилируемые фасады.
3. Отмостки, ливневая канализация, ограждения и благоустройство.
4. Сметы, объёмы, материалы, себестоимость, прибыль и закупки.
5. Коммерческие предложения, договоры, акты, продажи и управление проектами.
6. Проверяемая база знаний из нормативов, инструкций производителей, внутренних документов и прайсов.
7. Расчётные функции, работа с файлами, а позднее — сохранение проектов и истории чатов в отдельном защищённом хранилище.

## Безопасность данных

- Никогда не коммитить API-ключи, пароли, токены, паспортные данные, банковские реквизиты физлиц, приватные клиентские документы или иные секреты.
- В GitHub хранить проектную документацию и очищенные от персональных данных сводки, а не автоматически публиковать полные личные разговоры.
- История пользовательских чатов внутри приложения требует отдельного хранилища, авторизации, правил доступа и политики хранения; Git-коммиты не заменяют базу данных приложения.
- Инженерные решения по фундаментам, подпорным стенам и несущим конструкциям должны проверяться ответственным специалистом с учётом исходных данных объекта.
