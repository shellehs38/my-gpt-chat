## Обязательное правило: прямая ссылка на ИИ-помощника после каждого изменения

**Постоянное требование владельца ООО «СВОИ ЛЮДИ».** После **любого** изменения ИИ-помощника — структуры, интерфейса, логики, кода, функциональности, интеграций, конфигурации, версии, ветки, сборки, исправления ошибки или развёртывания — в сообщении с результатом **обязательно давать прямую кликабельную ссылку на помощника**.

- Если изменение выполнено только в GitHub и ещё не развёрнуто, указать прямую ссылку на действующего помощника **https://my-gpt-chat-theta.vercel.app** и явно написать, что изменения на нём пока нет. Дополнительно дать ссылку на изменённую ветку или файл.
- Если создано Preview-развёртывание, дать **прямой URL именно нового Preview помощника**, указать фактический статус сборки (READY/BUILDING/ERROR и т. д.) и при необходимости отдельно ссылку на Production.
- Если изменение опубликовано в Production с явного разрешения владельца, дать прямую ссылку **https://my-gpt-chat-theta.vercel.app** и подтвердить публикацию только после проверки.
- Никогда не подменять ссылку на помощника ссылкой на GitHub или Vercel Dashboard. Не выдавать ссылку на старый Preview за новую. Не заявлять о доступности, пока развёртывание не подтверждено.
- Правило действует **после каждого изменения без напоминаний**; оно не даёт разрешения менять Production, секреты или рабочую базу без отдельного согласования.

> **ОБЯЗАТЕЛЬНО: фирменные логотипы.** Во всех документах, фотографиях, изображениях, рекламе, буклетах, сметах, PDF/Excel, сайтах и проектах компании использовать **только** три оригинальных PNG из `shellehs38/svoi-lyudi-facade-site`: `logo-sl-approved-dark.png`, `logo-sl-approved-light.png`, `logo-sl-approved-transparent.png`. Подобрать по фону и встроить в результат. **Не создавать новые логотипы, не заменять утверждённые SVG/AI-знаками, не удалять существующие файлы без отдельного указания владельца.** Полный порядок: [BRAND_LOGO_RULES.md](BRAND_LOGO_RULES.md).

# Документы «СВОИ ЛЮДИ»

Постоянное указание владельца: каждый новый документ компании, включая смету, КП, договор, акт, ведомость и отчёт, должен содержать подлинный логотип SL / «СВОИ ЛЮДИ» в шапке. Перед подготовкой документов или изменением их выгрузки читай [DOCUMENT_BRANDING.md](DOCUMENT_BRANDING.md).

Используй утверждённый PNG из `public/brand/logo-sl-approved-light.png`; для другого фона выбирай подходящий подлинный вариант из указанного источника. Проверяй наличие изображения в готовом файле и печати. Сохраняй текущие данные, расчёты, авторизацию и правила работы с Google Таблицей.

## Память кодовой базы

Для навигации по коду используй Codebase Memory, когда MCP подключён. Настройка и CLI: [docs/CODEBASE_MEMORY.md](docs/CODEBASE_MEMORY.md). Перед работой читай [docs/CODEBASE_MEMORY_ADR.md](docs/CODEBASE_MEMORY_ADR.md); актуальные правила владельца и исходники имеют приоритет над индексом.

После изменения кода обновляй индекс командой `npm run memory:index`. Проверяй `index_status`, `get_graph_schema` и `check_index_coverage` для затронутых файлов; подтверждай найденные связи чтением исходника и тестами. Если MCP в текущем клиенте недоступен, используй описанный CLI или обычное чтение кода и укажи ограничение. Не выдавай наличие конфигурации за активное подключение к текущему чату. Бинарники, локальные базы, ключи и пользовательские данные в коммит не добавляй.
