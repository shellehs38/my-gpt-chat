# СВОИ ЛЮДИ — приложение для iPhone и Windows

Предварительная нативная версия 0.2.0 на Flutter 3.47.8. Интерфейс приложения не использует браузер или WebView. Данные объектов, расчётов и диалогов сохраняются на устройстве.

## Состав

- Объекты строительства и локальное сохранение данных в JSON.
- Калькулятор сайдинга с проверяемой геометрией, неизвестными ценами и раздельными материалами и работами.
- Библиотека материалов и встроенные иллюстрированные инструкции. Предоставленный PDF «Металл Профиль», 3-е издание, 2019 год, включает 26 страниц; актуальность для конкретного изделия проверяется отдельно.
- Серверный диалог с помощником в шести направлениях. Отдельная история и черновик для каждого объекта и направления; при отправке прилагаются название, адрес и последний сохранённый расчёт.
- Нативное формирование документов и системные операции с файлами.

Фактическую готовность конкретной функции подтверждают исходники и проверки. Наличие проекта iOS/Windows само по себе не означает готовый установочный пакет.

## Вход в помощник

Для ответов ИИ нужны интернет, опубликованные `/api/native/auth` и `/api/native/chat` и пароль существующего помощника. Ключ OpenAI остаётся на сервере. Пароль не записывается в файлы, токен входа хранится только в памяти приложения до 12 часов; после закрытия приложения нужно войти снова. Выход удаляет локальную сессию, но не отзывает уже выданный серверный токен. Уже отправленный запрос может завершиться на сервере; его поздний ответ после выхода игнорируется.

Истории включаются в JSON-резервную копию, пароль и токен — никогда. При импорте диалоги получают новые ID и привязываются к копиям объектов. Очистка диалога явно удаляет его локальные сообщения. Синхронизация между iPhone и Windows пока не подключена.

Сервер по умолчанию: `https://my-gpt-chat-theta.vercel.app`. Для другого принадлежащего владельцу HTTPS-сервера при сборке задайте `--dart-define=ASSISTANT_BASE_URL=https://your-host.example`. Произвольный адрес и секреты в интерфейсе пользователя не вводятся. Сборка клиента не публикует сервер автоматически; проверяйте развёртывание отдельно.

## Проверка исходников

Установите Flutter 3.47.8 и выполните из корня проекта:

```sh
flutter pub get --enforce-lockfile
flutter analyze --fatal-infos
flutter test
```

Тесты виджетов проверяют Flutter-интерфейс, но не заменяют запуск на настоящем iPhone и Windows. В Linux нельзя подтвердить сборку этих двух платформ.

## Запуск и сборки

- **Windows:** Windows и Visual Studio с компонентами **Desktop development with C++**; запуск `flutter run -d windows`, сборка `flutter build windows --release`.
- **iPhone:** macOS и Xcode, настройка устройства и подпись Apple. `flutter build ios --release --no-codesign` проверяет компиляцию и создаёт неподписанную `.app`, которую нельзя считать готовой к обычной установке.
- **GitHub Actions в общем репозитории:** корневой workflow `Native app preview · iPhone and Windows` проверяет исходники и собирает обе платформы. Windows-пакет содержит Microsoft CRT и проходит проверку запуска процесса. Для извлечённого отдельного Flutter-проекта есть ручной workflow `Native builds` в `.github/workflows/native-builds.yml`. Подписания Apple и публикации в магазинах нет.

Подробный порядок и ограничения: [docs/NATIVE_BUILD.md](docs/NATIVE_BUILD.md).
