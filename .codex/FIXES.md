Основание: аудит версии `2cc70c27baf847f27168fa4f446bc29422893c14` репозитория `shellehs38/my-gpt-chat`. Исправления относятся к приложению помощника, а не к фасадному сайту Wix. MAX остаётся на паузе.

Расчёт использует десятичные целые значения и округление до копеек без ошибок двоичной арифметики денег. Строки итогов не включаются в сумму повторно. Неизвестные количества/цены не заменяются нулями; вместо полного итога показывается известная часть с явной отметкой неполноты. Исходный текстовый итог модели не выдаётся за пересчитанный итог после ручных правок.

## Проверка

Результаты финального прогона фиксируются в `validation.json`. Тесты API используют подменённый провайдер; реальных оплачиваемых вызовов OpenAI не выполнялось.

Независимая проверка интерфейса в Chromium на мобильной и настольной ширине подтвердила изоляцию вариантов, видимость единиц, редактирование на компьютере, актуальные копирование и выгрузку, восстановление после перезагрузки, включение выбранной отредактированной версии в следующий вопрос и повтор именно сбойного запроса. Проверены сообщения об ошибке хранилища, сохранение повреждённой резервной копии и отказ перезаписывать её автоматически.

## Настройка перед использованием

Сервер должен получить `OPENAI_API_KEY`, `ASSISTANT_ACCESS_PASSWORD` и независимый `ASSISTANT_SESSION_SECRET`; примеры названий и требования находятся в `.env.example` и README. Секреты в GitHub не сохраняются. Без ключа модель не имитируется, без настроенного входа её API закрыт.

Счётчики запросов являются защитой на экземпляр процесса. В нескольких serverless-экземплярах для общего бюджета нужны общие лимиты хостинга/провайдера. Локальные счётчики не объявляются глобальным финансовым ограничителем.

Проект и сметы сохраняются в конкретном браузере, а не в облачной базе; резервную копию нужно экспортировать для переноса. Качество реальных ответов модели, актуальность предоставленных цен и технических решений требуют отдельной проверки на настоящих данных. Правильная арифметика не подтверждает обмеры или конструкцию фасада.

## Публикация и откат

Изменения сохраняются в истории Git; исходная версия доступна по указанному выше коммиту. Результат автоматической публикации проверяется отдельно по статусам GitHub/Vercel и не подменяется результатом локальной сборки. Успешная сборка не означает, что на хостинге уже настроены секреты.
