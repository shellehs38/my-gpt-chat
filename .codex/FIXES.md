# Исправления строительного помощника

## Версия 1.4.0 — исправления по экспертному аудиту

Основание: повторный аудит версии `d919858960a35da40e6af2e3b0a6567e4bb92f3f` репозитория `shellehs38/my-gpt-chat`.

- Сервер один раз готовит клиентские цены работ перед выдачей сметы. Материалы, прямые расходы и цены, уже отмеченные как конечные, сохраняются без повторного изменения. В режимах документов и общих ответов это правило не применяется.
- Устаревшие денежные формулы и итоги ответа модели больше не показываются как действующие после пересчёта. Геометрические формулы сохраняются; экран, контекст и выгрузка используют суммы структурированных таблиц.
- Явное указание «не фасад», падежные формы и начало новой задачи не наследуют фасадный контекст из старой переписки.
- Существующая строка установки, сборки, разборки или демонтажа строительных лесов предотвращает добавление повторной позиции.
- Сохранённый проект, импорт, экспорт и очистка скрыты до входа. Обычный выход синхронно сохраняет последнюю правку; истечение сессии сохраняет черновик и повтор запроса. Очистка удаляет проект, незавершённую операцию учёта и все локальные очереди Drive, ставит автосохранение на паузу во всех открытых вкладках и сохраняет облачную историю.
- Защита нового проекта учитывает черновики и сбойные запросы во всех вкладках. Повреждённая локальная резервная копия не перезаписывается при обычном выходе без явного действия владельца.
- Мобильный интерфейс уплотнён и поле запроса перенесено перед справочными блоками: при ширине 390 px оно начинается на 651 px вместо 1134 px, горизонтальной прокрутки нет.
- Добавлены CSP и другие защитные HTTP-заголовки, закрывающий индексацию `robots.txt`, `noindex` и фирменная иконка. Публичный файл логотипа разрешён для экспортированного Markdown.
- Исправлен порядок проверки лимита входа: уже заблокированный адрес не расходует общий лимит владельца.

Локальные критерии релиза зафиксированы в `validation.json`. Общий распределённый лимит запросов и бюджета для всех serverless-экземпляров остаётся задачей следующего этапа.

## Исправления предыдущих версий

Основание: аудит версии `2cc70c27baf847f27168fa4f446bc29422893c14` репозитория `shellehs38/my-gpt-chat`. Исправления относятся к приложению помощника, а не к фасадному сайту Wix. MAX остаётся на паузе.

Расчёт использует десятичные целые значения и округление до копеек без ошибок двоичной арифметики денег. Строки итогов не включаются в сумму повторно. Неизвестные количества/цены не заменяются нулями; вместо полного итога показывается известная часть с явной отметкой неполноты. Исходный текстовый итог модели не выдаётся за пересчитанный итог после ручных правок.

## Проверка

Результаты финального прогона фиксируются в `validation.json`. Тесты API используют подменённый провайдер; реальных оплачиваемых вызовов OpenAI не выполнялось.

Независимая проверка интерфейса в Chromium на мобильной и настольной ширине подтвердила изоляцию вариантов, видимость единиц, редактирование на компьютере, актуальные копирование и выгрузку, восстановление после перезагрузки, включение выбранной отредактированной версии в следующий вопрос и повтор именно сбойного запроса. Проверены сообщения об ошибке хранилища, сохранение повреждённой резервной копии и отказ перезаписывать её автоматически.

## Настройка перед использованием

Сервер должен получить `OPENAI_API_KEY`, `ASSISTANT_ACCESS_PASSWORD` и независимый `ASSISTANT_SESSION_SECRET`; примеры названий и требования находятся в `.env.example` и README. Секреты в GitHub не сохраняются. Без ключа модель не имитируется, без настроенного входа её API закрыт.

Счётчики запросов являются защитой на экземпляр процесса. В нескольких serverless-экземплярах для общего бюджета нужны общие лимиты хостинга/провайдера. Локальные счётчики не объявляются глобальным финансовым ограничителем.

Проект и сметы сохраняются в конкретном браузере; после отдельного подключения Google Drive создаётся проверяемая облачная история для переноса и восстановления. JSON-экспорт остаётся независимой резервной копией. Качество реальных ответов модели, актуальность предоставленных цен и технических решений требуют отдельной проверки на настоящих данных. Правильная арифметика не подтверждает обмеры или конструкцию фасада.

## Публикация и откат

Изменения сохраняются в истории Git; исходная версия доступна по указанному выше коммиту. Результат автоматической публикации проверяется отдельно по статусам GitHub/Vercel и не подменяется результатом локальной сборки. Успешная сборка не означает, что на хостинге уже настроены секреты.
