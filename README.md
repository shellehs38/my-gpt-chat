ИИ-помощник для строительного бизнеса

О проекте

Персональный ИИ-помощник для ООО «СВОИ ЛЮДИ» — строительной компании из Иркутска.

Цель проекта — создать инструмент для помощи в управлении строительным бизнесом и автоматизации рабочих процессов.

Основные функции

* Фасадные работы: технологии, материалы и контроль качества.
* Сметы: расчёт объёмов, материалов и стоимости работ.
* Продажи: работа с клиентами и подготовка предложений.
* Документы: договоры, инструкции и чек-листы.
* Управление: финансы, сотрудники, сроки и задачи.

Этапы разработки

1. Создание основы приложения.
2. Разработка интерфейса чата.
3. Подключение ИИ через API.
4. Добавление инструментов для строительного бизнеса.
5. Тестирование и запуск.

Принципы работы

* Не выдумывать цены и технические характеристики.
* Проверять расчёты.
* Защищать ключи доступа.
* Разрабатывать проект поэтапно.

Статус

Разработка с нуля. Репозиторий используется для хранения кода и документации.
