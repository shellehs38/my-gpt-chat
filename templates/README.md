# Полевые формы фасадных работ

Формы для ООО «СВОИ ЛЮДИ» — Иркутск.

## Файлы

- `facade_survey_form.csv` — обследование фасада.
- `facade_measurement_sheet.csv` — обмеры стен и проёмов с формулами площади.
- `ventilated_facade_estimate.csv` — смета с автоматическим расчётом строк и итогами вариантов.
- `hidden_works_checklist.csv` — приёмка скрытых работ.

CSV открываются в Excel и других табличных редакторах. Для удобного использования с форматированием, выпадающими списками и отдельными вкладками см. Excel-файл, подготовленный в рамках проекта.

## Как пользоваться сметой

В колонке «Вариант» используйте:
- `Оба` — позиция входит в оба варианта;
- `С утеплением` — позиция только для варианта с утеплением;
- `Без утепления` — позиция только для варианта без утепления.

Заполняйте количество и цену за единицу. Формула суммы умножает количество на цену. Итоговые строки суммируют общие позиции и позиции выбранного варианта. Не включайте одни и те же работы дважды.

## Важные ограничения

Шаблоны не назначают автоматически толщину утеплителя, шаг кронштейнов, тип и длину анкеров, число креплений или противопожарные решения. Эти данные определяются по фактическому зданию, проекту, обследованию основания и документации выбранного производителя. Незаполненные цены не считать нулевыми.
