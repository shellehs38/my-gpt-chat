# Обязательный логотип на документах ООО «СВОИ ЛЮДИ»

Правило владельца от 19 октября 2026 года: каждый новый документ компании оформляется с подлинным фирменным логотипом SL / «СВОИ ЛЮДИ». Правило действует по умолчанию, без повторного напоминания.

## Водяной знак во всех клиентских документах — 05.11.2026

Постоянное указание владельца: **любая смета и любой документ для клиента содержит крупный полупрозрачный водяной знак «СВОИ ЛЮДИ» по всей странице, на каждой странице документа**. Правило одинаково действует для файлов, подготовленных в чате ChatGPT и в строительном помощнике, без отдельного напоминания; при редактировании старых клиентских документов оно также применяется.

Область: клиентские сметы, КП, договоры, акты, счета, ведомости, графики, отчёты, приложения и другие выдаваемые клиенту документы. По умолчанию размещай крупную диагональную надпись через основное поле каждой страницы, с достаточной прозрачностью для чтения текста, таблиц, сумм, подписей и реквизитов. На каждом отдельном клиентском листе Excel и каждой странице его печатной версии проверяй знак отдельно. Для обязательных бланков сохраняй все предусмотренные поля и их читаемость.

Водяной знак **дополняет** подлинный PNG-логотип в шапке. Он должен быть встроен в итоговый PDF/DOCX/XLSX/HTML или печатную версию, открываться без интернета и сохраняться после экспорта. Фоновая картинка Excel, которая исчезает при печати, и знак только в интерфейсе не подтверждают выполнение правила. Перед выдачей открой готовый результат и проверь наличие знака на всех страницах. Если конкретный способ выгрузки пока не умеет встраивать знак, не утверждай, что файл уже соответствует этому правилу; подготовь и проверь клиентскую версию в поддерживаемом формате.

Обычные сообщения, технические CSV/JSON и рабочие базы не заменяют оформленный клиентский документ. Правило логотипа для внутренних документов сохраняется. Данное указание само по себе не означает, что ранее реализованные генераторы автоматически обновлены: применение подтверждается проверкой конкретного файла.

## Область применения
Сметы и их варианты, рабочие калькуляции, коммерческие предложения, договоры, акты, счета, ведомости, графики, отчёты, презентации и другие подготовленные документы, включая черновики, клиентские и внутренние версии. Применяется к PDF, DOCX, XLSX, HTML, презентациям и печатным представлениям. Обычные сообщения в чате и технические JSON/CSV-данные не заменяют оформленный документ.

- Используй оригинальные файлы, сохраняй пропорции, цвета и весь знак. Не генерируй и не перерисовывай похожий логотип.

## Размещение
Логотип по центру шапки первой страницы, над названием документа; для A4 ориентировочная ширина 35–50 мм, без растяжения и обрезки. На следующих страницах используй небольшой знак в колонтитуле, если формат поддерживает повторение. В XLSX добавляй изображение на каждый оформленный печатный лист и проверяй область печати. В PDF/DOCX/HTML встраивай само изображение, чтобы файл открывался без доступа к закрытому GitHub.

В рабочих базах клиентов и расходов сохраняй существующие заголовки, ID и формулы: оформляй отдельный отчёт или печатное представление, не сдвигай таблицу ради логотипа. На обязательных бланках используй предусмотренное место, сохраняя требуемые поля.

## Проверка перед выдачей
Открой готовый файл и убедись, что логотип виден, не обрезан, контрастен, не закрывает данные и остаётся в выгрузке/печати. Проверяй PDF, DOCX и XLSX отдельно: логотип в PDF не подтверждает его наличие в Excel. Если среда поддерживает только текст или CSV и не может встроить изображение, выдай это как текст/данные, явно отметь отсутствие оформленного файла и подготовь брендированную версию в доступном формате. Не называй документ окончательно оформленным без фактического логотипа.

Правило меняется только по прямому указанию владельца.

В веб-приложении основной PNG находится в `public/brand/logo-sl-approved-light.png`. Его байты встраиваются в HTML-документ. Markdown-копия содержит ссылку на тот же файл; резервный JSON проекта предназначен для восстановления данных.

## Подтверждение владельца от 05.11.2026 и прямая выгрузка

**Любой документ, любая смета и любой договор — обязательно с подлинным логотипом**, в том числе при редактировании старого документа. Это постоянное правило по умолчанию.

Под ответом веб-помощника доступны «Скачать PDF», «Скачать Word», «Скачать Excel» и «Скачать HTML». PDF/DOCX/XLSX формирует защищённый `POST /api/documents/export` через `lib/server/document-export.ts`; PNG проверяется по SHA-256 и встраивается в файл. Шрифты PDF включают кириллицу. На следующих страницах PDF/DOCX повторяется знак; в Excel изображение включено в печатную область оформленного листа. HTML также содержит байты PNG. Внешний доступ к GitHub для открытия готового файла не требуется. Не меняй цены и суммы договора при оформлении: экспорт использует текущую версию с пользовательскими правками, без повторного расчёта на сервере.

Причина потери изображения при прежнем переносе: текст/Markdown и буфер обмена передают только ссылку; сторонний редактор может не вставить картинку. Текстовая копия остаётся данными, а не оформленным документом. Для клиента выбирай готовый PDF/DOCX/XLSX/HTML. При недоступности или подмене подлинного PNG все новые бинарные выгрузки останавливаются; не создавай тихий вариант без логотипа. Проверяй готовые файлы по отдельности и визуально, не только наличие логотипа на странице сайта.
