# Исходники обновления «СВОИ ЛЮДИ — Стройпомощник»

В GitHub хранятся общие справочники строительной базы версии `0.2.17`.
Внутренние инструкции и метаданные частного плагина исключены из публичного
репозитория. Это не полный пакет плагина для самостоятельного восстановления.
Действующие MCP-настройки, остальные навыки и подлинные логотипы сохраняются в
частном релизе помощника.

Главный навык маршрутизирует строительные задачи в тематические справочники:

- фасадные системы и расчёт объёмов;
- организация строительных работ;
- сметы, план-факт, расходы и прибыль;
- качество, безопасность и логистика;
- карта первичных нормативных источников.

Справочники помогают подготовить расчёт и контрольные формы, но не заменяют
проект, обследование, ППР, техническую карту конкретной системы, решение
ответственного специалиста или действующую редакцию обязательного документа.

Дата проверки реквизитов карты источников: 20 октября 2026 года. Точный пункт и
действующую редакцию нужно проверять перед применением к конкретному объекту.
